How to chat without internet on Android

Two Android phones can exchange messages with no internet and no mobile data, as long as they are near each other and run the same offline chat app. The phones connect directly over Bluetooth and Wi-Fi Direct instead of going through a mobile network or a router.

By Jayarous Antony KS, developer of AirGrid. Published 17 November 2026.

When you need it

Mobile networks slow down or stop working when too many people use them at once, and they do not reach everywhere. Offline chat is useful in places like these:

  • Crowded events such as festivals, stadiums and New Year's Eve celebrations
  • Hiking, camping and other places with no signal
  • Travel, when you have no local data plan
  • Campuses, hostels and hotels with weak Wi-Fi
  • Network outages, as part of being prepared

How offline chat works

Every Android phone has Bluetooth and Wi-Fi radios. An offline chat app uses those radios to find other phones nearby and connect to them directly. No mobile tower, router or server is involved.

Some apps go one step further and build a mesh: each phone passes messages on to the next one, so a message can travel further than a single direct connection.

What you need before you go offline

  • The same offline chat app on every phone. Install it while you still have internet, because you cannot download an app without a connection.
  • Bluetooth and Wi-Fi switched on. Wi-Fi does not need to be connected to a network.
  • The permissions the app asks for, such as Bluetooth, Wi-Fi and location-related permissions. Android requires them for finding and connecting to nearby phones.
  • People within range. Bluetooth and Wi-Fi Direct are short-range, and distance and surroundings reduce it.

Set it up with AirGrid

AirGrid is an offline chat app for Android that works this way. Setting it up takes a few minutes:

  1. Install AirGrid from Google Play while you are online.
  2. Open it and allow the permissions it asks for.
  3. Ask the people you want to reach to install it too.
  4. When you are near each other, open AirGrid. Nearby users discover each other and join a local mesh.
  5. Use public nearby chat to talk to everyone connected, or private chat to message one person.

AirGrid can also send voice notes, photos and files when the local connection supports the transfer, and it has walkie talkie audio for short voice clips.

Limits to know

  • Offline chat only reaches people nearby who have the same app installed.
  • Range and speed vary with the phones, the Android version, distance, radio conditions and the number of people nearby.
  • It does not replace emergency services. If you need urgent help, call the local emergency number.

Common questions

Can two phones chat over Bluetooth without internet?
Yes. With the same offline chat app on both phones, messages travel directly between them over Bluetooth and Wi-Fi Direct. No internet, mobile data or router is needed.
Can I make calls without internet?
Not regular phone calls. With AirGrid you can send walkie talkie voice clips, and start a live one-to-one audio session called Rider Mode with a trusted contact nearby.
Does offline chat use mobile data?
No. Messages go straight from phone to phone, so no mobile data is used.
Does AirGrid work between Android and iPhone?
AirGrid is an Android app, so it connects Android phones that have it installed.
Do I need to prepare in advance?
Yes. Install the app and open it once while you have internet, and make sure the people you want to reach have it too.
